RFQ Portal — Complete File Inventory

Complete catalog of every backend router, database model, frontend component, and system utility file with descriptions.
📁 Root: rfq-portal/ ⚡ Stack: FastAPI + PostgreSQL + React (Vite) 🚀 Version: 2.0.0
🔍
🚀 1. Root System Files & Automation Scripts
File Location Contents & Functional Role
START_PORTAL.bat Launcher One-Click Startup Script: Checks and starts the PostgreSQL database, launches the FastAPI backend server on localhost:8000, boots Vite frontend on localhost:5173, and automatically opens the portal in the default browser.
STOP_PORTAL.bat Utility One-Click Shutdown Script: Gracefully finds and terminates background Python (uvicorn) and Node.js (Vite) processes running the portal.
ALL_FILES_DIRECTORY_AND_DESCRIPTIONS.md Documentation Master File Index: Comprehensive markdown document providing full path listings and descriptions for all project files.
SYSTEM_DESIGN_AND_DB_DOCUMENTATION.md Documentation System Design & Database Architecture: Detailed specification covering PostgreSQL schemas, entity relationships, security models, and lifecycle states.
AGIC_RFQ_Portal_Complete_Master_Documentation.html Documentation Interactive Master HTML Manual: Standalone offline reference manual containing diagrams, workflows, API specifications, and architecture flows.
AGIC_RFQ_Portal_KT_and_User_Guide.html KT Guide Knowledge Transfer & User Guide: Complete interactive guide for Vendors and Officers with step-by-step submission instructions and role guides.
⚙️ 2. Backend Application (backend/)
File Location Contents & Functional Role
backend/app/main.py Core FastAPI App Entrypoint: Configures CORS middleware, mounts /uploads static directory, registers API routers, customizes OpenAPI metadata, and mounts Scalar interactive API docs at /scalar.
backend/run.py Server Uvicorn Runner: Boots the FastAPI app on 0.0.0.0:8000 with auto-reload enabled.
backend/seed.py Database Database Seeding Script: Populates initial PostgreSQL tables with Officer accounts, sample eligible vendors, active RFQs with RFQ Items, and quotation submissions.
backend/app/core/config.py Config Application Settings: Manages environment variables, database URI, JWT secret key, token expiration, and upload directories.
backend/app/core/database.py Database SQLAlchemy Engine: Initializes PostgreSQL database connection engine, SessionLocal session factory, and get_db dependency.
backend/app/core/security.py Security Hashing & JWT Token Handler: Password hashing via bcrypt, password verification, and JWT creation with subject and role claims.
backend/app/core/dependencies.py RBAC Auth Dependencies & Guards: Role-based access control handlers (get_current_user, require_ce, require_applicant, require_super_admin).
backend/app/models/schema.py ORM Models Database Entities (PostgreSQL): Defines 14 tables including CEUser, Applicant (with vendor_type), RFQTender (with quotation_valid_upto), RFQJob (with category, unit_rate, amount), Application, and ApplicationStatusHistory.
backend/app/routers/auth.py Endpoints Auth API Router: Handles OTP generation/verification, Vendor registration with 4 eligible categories, Vendor login, Officer login, and GET /api/auth/me with eligibility check.
backend/app/routers/tenders.py Endpoints RFQ Lifecycle Router: Creates, lists, updates, and publishes RFQs. Manages RFQ Items (Supply Item vs Only Rate), quotation validity periods, and document attachments.
backend/app/routers/applications.py Endpoints Quotations & Review Router: Enforces Vendor Eligibility on submissions, enforces Strict Officer Authorization (403 for non-creator officers), manages evaluation decisions (ACCEPTED/REJECTED), and generates dynamic ZIP document downloads.
backend/app/routers/clarifications.py Endpoints Clarifications Router: Handles pre-bid query submission by vendors and official replies by departmental officers.
backend/app/routers/stats.py Endpoints Analytics Router: Provides dashboard metrics scoped strictly to RFQs created by the logged-in officer.
backend/app/schemas/auth.py Schemas Auth Pydantic Models: Validates OTP requests, registration schemas with vendor types, and login models.
backend/app/schemas/tender.py Schemas RFQ Pydantic Models: Validates RFQ Items (category, unit rate, amount), quotation validity periods, and tender responses.
backend/app/schemas/application.py Schemas Application Pydantic Models: Validates quotation submissions, Annexure II capabilities, Annexure III itemized pricing breakdown, and status updates.
backend/app/schemas/clarification.py Schemas Clarification Schemas: Request and response models for pre-bid queries.

File Location Contents & Functional Role

frontend/src/api/client.js Network Axios API Client: Preconfigured HTTP client attaching JWT tokens to outgoing requests and handling global error responses.
frontend/src/context/AuthContext.jsx State Auth Context Provider: React Context managing user authentication, login state, role persistence, and logout workflows.
frontend/src/components/Navbar.jsx UI Component Header Navigation: Displays RFQ Portal branding, role-based navigation buttons, active user info, and avatar menu.
frontend/src/components/Footer.jsx UI Component Portal Footer: Official state government branding, links, contacts, and copyright information.
frontend/src/components/StatusBadge.jsx UI Component Status Pill Component: Dynamic color-coded badges for RFQ states (PUBLISHED, CLOSED) and quotation evaluation states (ACCEPTED, REJECTED, SUBMITTED).
frontend/src/components/CountdownTimer.jsx UI Component Live Deadline Countdown: Real-time countdown timer showing remaining days, hours, minutes, and seconds for RFQ submission.
frontend/src/pages/Home.jsx Page Public Home Page: Hero banner, search bar, active RFQs directory, category filters, and live statistical counters.
frontend/src/pages/TenderDetails.jsx Page RFQ Details Dossier: Detailed RFQ view with Quotation Validity Period, RFQ Items Schedule (Supply Item vs Only Rate), EMD amounts, and pre-bid Q&A.

frontend/src/pages/auth/ApplicantRegister.jsx Page Vendor Registration Page: Registration form with mandatory 4 eligible vendor categories, OTP verification, GSTIN, and PAN details.
frontend/src/pages/auth/CELogin.jsx Page Officer Portal Login: Departmental login page for Chief Engineers and Executive Officers.
frontend/src/pages/applicant/ApplicantDashboard.jsx Page Vendor Workspace: Vendor profile badge, eligibility status indicator, submission counters, and active RFQ shortcuts.
frontend/src/pages/applicant/MyApplications.jsx Page Vendor Quotations Matrix: List of all submitted quotations with custom amounts, dates, and live review statuses.
frontend/src/pages/applicant/SubmitQuotation.jsx Page Quotation Submission Wizard: Multi-step quotation workflow covering Eligibility Check, Covering Letter, RFQ Items selection, Annexure II, Annexure III pricing, and EMD documents.
frontend/src/pages/ce/CEDashboard.jsx Page Officer Executive Panel: Dashboard showing RFQs created by the officer, received quotation counts, pending reviews, and RFQ table.
frontend/src/pages/ce/CreateTender.jsx Page Raise New RFQ: Creation form for Officers to draft and publish RFQs, set Quotation Validity dates, and add multiple RFQ Items with unit rates and quantities.
frontend/src/pages/ce/TenderSubmissions.jsx Page Quotation Submissions Matrix: Comparative price matrix of all vendor bids. Protected by Strict Officer Authorization Guard.
frontend/src/pages/ce/ApplicationReview.jsx Page Quotation Evaluation & Award Dossier: Officer evaluation view with vendor profile, line items, ZIP document download, and ACCEPT/REJECT decision box.
frontend/src/pages/admin/ApiWorkbench.jsx Developer Interactive API Workbench: Dedicated development console at /developer to inspect and execute all backend REST endpoints directly.
